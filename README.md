# ATS Resume Tailor

Local website for creating a targeted 1-2 page ATS-friendly resume from an existing resume and a job description.

## Run

```powershell
npm install
npm run dev -- --port 5173
```

Open:

```text
http://127.0.0.1:5173
```

## Features

- Paste or upload an old resume as TXT, DOCX, or PDF.
- Paste a job description.
- Generate a 1-page or 2-page tailored resume draft.
- See matched and missing job keywords.
- Edit the final resume directly.
- Copy, download as TXT, print, or choose Save as PDF from the print dialog.

The tool drafts an ATS-friendly resume, but always review the final resume for accuracy before applying.
